Advection

advection! performs one in-place, directional semi-Lagrangian step. It interpolates along one axis of an array; callers control the time loop and compose directional steps when they need operator splitting.

using SemiLagrangian

mesh_x = UniformMesh(0.0, 1.0, 128)
mesh_v = UniformMesh(-6.0, 6.0, 96)
interp_x = Lagrange(5)
interp_v = Lagrange(5)
f = [exp(-v^2 / 2) * (1 + 0.01cos(2pi * x)) for x in mesh_x.points, v in mesh_v.points]

# The x velocity varies by velocity line; advect along array dimension 1.
vx = mesh_v.points
advection!(f, mesh_x, vx, 0.01, interp_x; dim = 1)

# The velocity is constant along each velocity line and varies with x.
electric_field = sin.(2pi .* mesh_x.points)
advection!(f, mesh_v, electric_field, 0.01, interp_v; dim = 2)

The departure-point shift in grid units is -dt * velocity / step(mesh). Velocity may be a scalar, an array with one value per transverse line, or an array matching the data shape for pointwise velocities (the latter requires an AbstractInterpolation). The mesh length must match the selected data dimension. Interpolation boundary behavior is determined by its boundary condition.

For repeated two-operator compositions, describe the directional operators once and let split_advection! alternate them according to a splitting coefficient vector. The first operator is applied at odd stages; the second at even stages. This works with strangsplit, triplejumpsplit, and the other coefficient helpers.

op_x = AdvectionOperator(mesh_x, vx, interp_x; dim = 1)
op_v = AdvectionOperator(mesh_v, electric_field, interp_v; dim = 2)
split_advection!(f, op_x, op_v, strangsplit(0.01))
SemiLagrangian.hamsplit_3_11 — Method
hamsplit_3_11(dt, fltrace = false)

Sixth-order splitting scheme with 11 stages (symmetric), whose coefficients depend on powers of dt and are computed in high precision. Returns the vector of 11 stage lengths.

SemiLagrangian.magicsplit — Method
magicsplit(dt)

"Magic" splitting for rotations: returns [tan(dt/2), sin(dt), tan(dt/2)]. These coefficients decompose a rotation of angle dt into three shears and are exact for a rotation advection (the splitting error vanishes), unlike strangsplit.

source
SemiLagrangian.nosplit — Method
nosplit(dt)

Trivial splitting with a single stage of length dt. Returns dt * [1]. Useful when only one operator is advanced.

source
SemiLagrangian.order6split — Method
order6split(dt)

Sixth-order splitting with 23 stages (tabulated coefficients, adjusted so that the sums of the coefficients of each operator are exact). Returns the vector of stage lengths multiplied by dt.

source
SemiLagrangian.standardsplit — Method
standardsplit(dt)

Lie (first-order) splitting: the coefficients dt * [1, 1] advance the first operator and then the second one, each for the full time step dt.

source
SemiLagrangian.strangsplit — Method
strangsplit(dt)

Strang (second-order) splitting: returns dt * [1/2, 1, 1/2], i.e. a half step of the first operator, a full step of the second one, then a half step of the first one again.

source
SemiLagrangian.table2split — Method
table2split(dt)

Symmetric splitting scheme with 9 stages built from tabulated coefficients that depend on dt. Returns the vector of 9 stage lengths.

source
SemiLagrangian.triplejumpsplit — Method
triplejumpsplit(dt)

Fourth-order splitting obtained by the triple-jump composition of the Strang scheme. Returns the 7 coefficients (stages alternate between the first and the second operator).

SemiLagrangian.advection! — Method
advection!(data, mesh, velocity, dt, interpolant; dim=1)

Advect data in place along dimension dim for one time step dt. mesh describes the advected dimension. velocity may be a scalar, an array with one value for each line perpendicular to dim, or an array with the same shape as data for a pointwise velocity field.

The characteristic shift is -dt * velocity / step(mesh). Call this function repeatedly to compose directional advections or construct a time-splitting scheme. Pointwise velocity fields require an AbstractInterpolation; other interpolants support scalar and per-line velocities.

source
SemiLagrangian.split_advection! — Method
split_advection!(data, first, second, coefficients)

Apply a two-operator splitting in place. Stages alternate between first and second, beginning with first; coefficients are the time steps for the individual stages, such as the result of strangsplit(dt).
