FastInterpolations.jl

FastInterpolations.jl provides cubic-spline interpolation, including periodic boundary conditions. It can be used directly with the uniform grids used in the examples:

using FastInterpolations

n = 100
xi = 1.0:n
u = sin.(2π .* (0:n-1) ./ n)
alpha = 0.5

u_shifted = cubic_interp(
    xi,
    u,
    xi .+ alpha;
    bc=PeriodicBC(endpoint=:exclusive),
)

endpoint=:exclusive is appropriate for periodic grids that omit the duplicated endpoint. The query coordinates are expressed in the same units as xi; here alpha shifts the interpolated values by that many grid points. See examples/landau-damping.jl for a complete periodic Vlasov-Poisson example.

CubicSpline wrapper

CubicSpline wraps FastInterpolations.jl with the package's interpolate! interface for a uniform periodic grid. The input and output arrays have n elements, with the duplicated periodic endpoint excluded. The shift is measured in grid cells; a positive shift samples the input to the right of each grid point.

using SemiLagrangian

n = 100
x = (0:n-1) ./ n
u = sin.(2pi .* x)
shift = 0.5
expected = sin.(2pi .* (x .+ shift / n))

interpolant = CubicSpline(n)
output = similar(u)
interpolate!(output, u, shift, interpolant)

println("Maximum error: ", maximum(abs.(output .- expected)))
Maximum error: 4.060714520193187e-8

SemiLagrangian.CubicSpline — Type
CubicSpline(nx)

Cubic spline interpolation object for periodic 1D uniform grids.

Arguments

  • nx::Int: number of grid points in the periodic domain.

Notes

This wrapper uses FastInterpolations.jl's cubic_interp! under the hood with periodic boundary conditions. It provides a small adapter exposing the SemiLagrangian interpolate! API.

Example

using SemiLagrangian

n = 100
u = sin.(2π .* (0:n-1) ./ n)
u_out = zeros(n)

cs = CubicSpline(n)
interpolate!(u_out, u, 0.5, cs)  # shift by 0.5 grid points

SemiLagrangian.interpolate! — Method
interpolate!(u_out, u, alpha, interp::CubicSpline)

Interpolate array u onto u_out shifted by alpha grid points using cubic splines. This calls cubic_interp! from FastInterpolations.jl with periodic boundary conditions.

Arguments

  • u_out: preallocated output array (length interp.nx)
  • u: input array (length interp.nx)
  • alpha: fractional shift in units of grid spacing (can be non-integer)
  • interp: CubicSpline interpolation object
