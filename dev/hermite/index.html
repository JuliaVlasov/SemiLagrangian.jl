Hermite

The Hermite line interpolant accepts the same bc keyword as Lagrange: PeriodicBC() is the default, while ExtrapolationBC() keeps stencils within the data line and extrapolates at its ends.

Example

Shift a periodic function by a fraction of a grid cell and compare the result with its exact value. The periodic grid excludes its repeated endpoint, and a positive shift samples the input to the right of each grid point.

using SemiLagrangian

n = 128
x = (0:n-1) ./ n
u = sin.(2pi .* x)
shift = 0.3
expected = sin.(2pi .* (x .+ shift / n))

interpolant = Hermite(5)
output = similar(u)
interpolate!(output, u, shift, interpolant)

println("Maximum error: ", maximum(abs.(output .- expected)))
Maximum error: 1.2792675996298186e-7

Reference

SemiLagrangian.Hermite — Type
Hermite(order::Int, T::DataType = Float64; bc = PeriodicBC(), flbis = false)

Hermite interpolation of the given order for numbers of type T, with boundary condition bc (PeriodicBC or ExtrapolationBC). order must be congruent to 1 modulo 4 (or to 3 modulo 4 when flbis = true).
