Interpolations

SemiLagrangian provides general-purpose line interpolants as well as specialized methods for repeatedly shifting data on a one-dimensional, uniform periodic grid. This page compares the specialized periodic methods (LagrangeFFT, Spectral, LocalLagrange, CubicSpline) with the general-purpose interpolants (Lagrange, Hermite, BSplineLU, BSplineFFT).

All interpolants use the same in-place interface:

interpolate!(output, input, shift, interpolant)

shift is measured in grid points, not physical-coordinate units. The interpolated values correspond to sampling the input at i + shift; positive shifts therefore move a sampled profile to the left. The input and output must have the grid length used to construct the interpolant. Each method treats the data as periodic, wrapping stencil indices or Fourier phases as needed. Unlike the general Lagrange and Hermite interpolants, these specialized types do not take a bc keyword: periodicity is built into them.

Compare the methods

The following example compares each method with the exact shift of a smooth periodic function. Each interpolant and output buffer is created once and reused. The general-purpose interpolants are used with their default periodic boundary condition (PeriodicBC()):

using SemiLagrangian

n = 128
x = (0:n-1) ./ n
u = sin.(2pi .* x) .+ 0.2 .* cos.(6pi .* x)
shift = 0.3
expected = sin.(2pi .* (x .+ shift / n)) .+
    0.2 .* cos.(6pi .* (x .+ shift / n))
output = similar(u)
methods = (
    "Lagrange FFT" => LagrangeFFT(n, 7),
    "Spectral" => Spectral(n),
    "Local Lagrange" => LocalLagrange(7),
    "Cubic spline" => CubicSpline(n),
)

for (name, interpolant) in methods
    interpolate!(output, u, shift, interpolant)
    println(rpad(name, 20), " max error = ", maximum(abs, output .- expected))
end

general = (
    "Lagrange (order 7)" => Lagrange(7),
    "Hermite (order 5)" => Hermite(5),
    "B-spline LU (order 7)" => BSplineLU(7, n),
    "B-spline FFT (order 7)" => BSplineFFT(7, n),
)

for (name, interpolant) in general
    interpolate!(output, u, shift, interpolant)
    println(rpad(name, 24), " max error = ", maximum(abs, output .- expected))
end

Choosing a method

MethodApproachConsider it when
Spectral(n)Fourier phase shiftThe data is smooth and high accuracy is important. Discontinuities can cause Gibbs oscillations.
LagrangeFFT(n, stencil)Lagrange interpolation with FFT-based periodic convolutionYou want a high-order periodic interpolant and can afford FFT workspaces.
LocalLagrange(stencil)Local, fixed-width polynomial stencilShifts are small and avoiding FFT setup is useful.
CubicSpline(n)Cubic interpolation through the FastInterpolations.jl backendA convenient periodic cubic spline is sufficient.
Lagrange(order)Local Lagrange stencil, periodic or extrapolated boundariesYou need non-periodic boundaries or a different element type (BigFloat, Rational...).
Hermite(order)Local Hermite interpolation using derivative estimatesYou want a compact stencil with the Hermite construction (order 5, 9, ... or flbis=true with 3, 7, ...).
BSplineLU(order, n)B-spline interpolation with an LU-factorised spline systemYou need periodic B-splines and want an LU solve.
BSplineFFT(order, n)Periodic B-spline interpolation solved with FFTsYou need periodic B-splines and want an FFT solve.

The specialized interpolants allocate working arrays when constructed. Reuse each object for successive time steps rather than constructing one per call.

Stencil and order choices

LagrangeFFT takes a grid length and a supported odd stencil width (for example, LagrangeFFT(n, 7)). LocalLagrange takes only the odd stencil width; the implementation supports widths 3, 5, 7, 9, and 11. Its weights are intended for small offsets, preferably within about one grid cell. For larger shifts, split the time step or choose an FFT-based method.

SemiLagrangian.AbstractBoundaryCondition — Type

Abstract supertype for the boundary conditions used by line interpolants.

A boundary condition decides how an interpolation stencil of order + 1 points is built when it reaches the ends of the data line. The concrete subtypes are PeriodicBC and ExtrapolationBC. It is used as the bc type parameter of AbstractInterpolation and selected with the bc keyword of the constructors, for example Lagrange(5; bc = ExtrapolationBC()).

SemiLagrangian.AbstractInterpolation — Type

Abstract supertype of all the line interpolation methods (Lagrange, Hermite, BSplineLU, BSplineFFT).

An interpolation of order order evaluates the function at a shifted position using a stencil of order + 1 grid points. The shift is split into an integer part (in grid cells) and a fractional part in [0, 1); the weights of the stencil only depend on the fractional part and are given by a table of polynomial functions.

Type parameters

  • T : type of number on which the interpolation works (Float64, BigFloat, ...)
  • bc : boundary condition type, PeriodicBC or ExtrapolationBC
  • order : order of the interpolation (stencil of order + 1 points)

Implementation constraints

  • tabfct::Vector : this field must be present in the implementation, it is a table of order + 1 functions of the fractional shift that give the weights of the stencil.
  • Methods needing a preprocessing of the line (such as B-splines, which solve a linear system to get the spline coefficients) must specialize preprocess, preprocess! and is_preprocess_identity.
source
SemiLagrangian.ExtrapolationBC — Type
struct ExtrapolationBC <: SemiLagrangian.AbstractBoundaryCondition

Non-periodic boundary condition: interpolation stencils never leave the data line. Near the ends the stencil is shifted inside the line and the interpolating polynomial is used to extrapolate, so the result is less accurate close to the boundaries than in the interior. This is the boundary condition to use for non-periodic variables (for example a velocity coordinate).

Example

interp = Lagrange(5; bc = ExtrapolationBC())
source
SemiLagrangian.PeriodicBC — Type
struct PeriodicBC <: SemiLagrangian.AbstractBoundaryCondition

Periodic boundary condition: the data line is considered as one period of a periodic function, so interpolation stencils wrap around the ends of the line (the point after the last one is the first one). This is the default boundary condition of Lagrange, Hermite and BSplineLU, and the only one supported by BSplineFFT.

Example

interp = Lagrange(5; bc = PeriodicBC())

SemiLagrangian.interpolate! — Method

Multidimensional version of the periodic interpolation with precomputed weights: fp[i] = fi(x_i + decint + frac) for every index i, with a tensor product stencil.

Arguments

  • fp::AbstractArray{T,N} : output array
  • fi::AbstractArray{T,N} : input array (same size as fp)
  • decint::NTuple{N,Int} : integer part of the shift along each dimension, in grid cells
  • precal::Array{T,N} : tensor product of the stencil weights of each dimension
  • interp::Vector : the N interpolations (periodic boundary condition), one per dimension
  • tabmod : precomputed index tables used to wrap indices (see gettabmod)

SemiLagrangian.interpolate! — Method

Multidimensional periodic interpolation with the shift of each grid point stored in the array bufdec: fp[i] = fi(x_i + bufdec[i]). Returns true.

Arguments

  • fp : output array
  • fi : input array (same size as fp)
  • bufdec : array of shifts (in grid cells), one per grid point
  • interp_t::AbstractVector : the N interpolations, one per dimension

Keyword arguments

  • tabmod : precomputed index tables used to wrap indices
  • mpid : unused, kept for compatibility
  • t_split::Tuple : if given together with cachethreads, split of the indices between threads
  • cachethreads::Vector{CachePrecal} : one weight cache per thread; when given the loop is multithreaded

SemiLagrangian.interpolate! — Method

Shift the data fi by dec grid cells and store the result in fp: fp[i] approximates the function sampled by fi at x_i + dec * dx. This is the simplest entry point: the integer and fractional parts of dec are separated and the stencil weights are computed for you. The boundary condition is the one of interp (PeriodicBC or ExtrapolationBC). To apply the same shift many times, use the variants taking precomputed weights.

Arguments

  • fp : output vector of length n
  • fi : input vector of length n
  • dec : offset in units of dx (grid cells), positive or negative, may be larger than 1
  • interp::AbstractInterpolation : interpolation implementation

Returns

Nothing useful; the result is stored in fp.

Example

n = 64
x = range(0, 1; length = n + 1)[1:n]
fi = sin.(2π .* x)
fp = similar(fi)
interpolate!(fp, fi, 0.3, Lagrange(5))  # fp ≈ sin.(2π .* (x .+ 0.3 / n))

SemiLagrangian.interpolate! — Method

Shift the data fi by an offset and store the result in fp, for an interpolation with ExtrapolationBC. The offset is given as an integer number of cells decint and the sets of stencil weights allprecal computed beforehand with all_stencil_weights(interp, decint, frac). Several sets are needed because the stencil is moved inside the line near its ends, where the result is extrapolated.

Arguments

  • fp::AbstractVector : output vector
  • fi::AbstractVector : input vector
  • decint : offset in units of dx
  • allprecal::Vector{Vector{T}} : stencil weights for each possible end stencil
  • interp::AbstractInterpolation{T, ExtrapolationBC, order} : interpolation implementation
  • tabmod=gettabmod(length(fi)) : precompute for "begin at one" modulo

Returns :

  • No return

SemiLagrangian.interpolate! — Method

Shift the data fi by an offset and store the result in fp, for an interpolation with PeriodicBC. The offset is given as an integer number of cells decint and the stencil weights precal for the fractional part, computed beforehand with stencil_weights(interp, frac). Precomputing them avoids recomputing the weights when the same shift is applied many times.

After the call fp[i] approximates fi evaluated at x_i + (decint + frac) dx. For an even-order BSplineLU, use SemiLagrangian.split_shift(interp, shift) to obtain decint and frac; its centered stencil requires a fractional shift between -0.5 and 0.5.

Arguments

  • fp::AbstractVector : output vector
  • fi::AbstractVector : input vector
  • decint : offset in units of dx
  • precal::Vector : vector of order + 1 weights from stencil_weights(interp, frac)
  • interp::AbstractInterpolation{T, PeriodicBC, order} : interpolation implementation
  • tabmod=gettabmod(length(fi)) : precompute for "begin at one" modulo

Returns :

  • No return
