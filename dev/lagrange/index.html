Lagrange

Lagrange

Lagrange(order) constructs a general-purpose interpolant using order + 1 points per stencil.

Lagrange and Hermite accept a bc keyword. The default, PeriodicBC(), wraps interpolation stencils around the ends of the data line. Use ExtrapolationBC() to keep stencils within the line and extrapolate near its ends:

using SemiLagrangian

periodic_interp = Lagrange(5; bc = PeriodicBC())
extrapolating_interp = Lagrange(5; bc = ExtrapolationBC())

LagrangeFFT

LagrangeFFT(n, stencil) applies a constant shift to a periodic line using FFT-based convolution. It takes the grid length and the stencil width:

interpolant = LagrangeFFT(100, 7)
SemiLagrangian.LagrangeFFT — Type
LagrangeFFT(nx, order)

Create a Lagrange interpolation object using FFT-based circulant approach for periodic 1D grids.

This implementation uses a global Lagrange polynomial interpolation via FFT, providing spectral accuracy for smooth periodic functions. The interpolation uses circulant matrix properties to efficiently compute interpolated values via convolution in Fourier space.

Arguments

  • nx::Int: Grid size (number of points)
  • order::Int: Stencil width (number of points). Supports odd orders: 3, 5, 7, 9, 11

LagrangeFFT is a subtype of AbstractInterpolation (through the internal AbstractShiftInterpolation) with the PeriodicBC boundary condition and Float64 numbers. It supports the in-place call interpolate!(u_out, u, alpha, lagr), with one constant shift for the whole line.

Fields

  • nx::Int: Grid size
  • order::Int: Polynomial order
  • w::Vector{Float64}: Pre-allocated weight vector
  • bfft::Vector{ComplexF64}: FFT of basis function weights
  • ufft::Vector{ComplexF64}: FFT of input data

Example

lagr = LagrangeFFT(100, 5)  # 100 grid points, order-4 polynomial

SemiLagrangian.interpolate! — Method
interpolate!(u_out, u, alpha, lagr::LagrangeFFT)

Interpolate array u by a displacement alpha (in grid units) using global Lagrange polynomials via FFT convolution.

Arguments

  • u_out::AbstractVector: Output array (will be modified in-place)
  • u::AbstractVector: Input array (periodic boundary conditions assumed)
  • alpha::Real: Shift amount in grid-point units. Can be any real number; periodic boundary conditions handle wrapping.
  • lagr::LagrangeFFT: FFT-based periodic Lagrange interpolation object

Description

This function computes the interpolated values using:

  1. Lagrange polynomial weights at fractional offset
  2. FFT-based circulant matrix approach for efficiency
  3. Periodic boundary conditions via modular arithmetic

For smooth periodic functions, this provides spectral (exponential) accuracy.

Example

lagr = LagrangeFFT(100, 5)
f = sin.(2π .* (0:99) ./ 100)
f_interp = zeros(100)
interpolate!(f_interp, f, 0.5, lagr)  # shift by 0.5 grid points

LocalLagrange

LocalLagrange(stencil) applies a local fixed-width stencil to a periodic line. The supported widths are 3, 5, 7, 9, and 11. It is intended for small shifts, preferably within one grid cell.

interpolant = LocalLagrange(7)
SemiLagrangian.LocalLagrange — Type
struct LocalLagrange{order} <: SemiLagrangian.AbstractShiftInterpolation{order}

Provides local Lagrange polynomial interpolation over periodic domains using fixed-width stencils of 3, 5, 7, 9, or 11 points. Boundary points are handled via periodic (circular) wrapping of the input array.

⚠️ Numerical Stability Disclaimer

This implementation uses local (finite-stencil) Lagrange interpolation and is not numerically stable for large shifts or high-order stencils on coarse grids.

The key limitations are:

  • Locality: Only a small neighbourhood of 2s points (where s is half the stencil width) contributes to each interpolated value. If the function varies significantly between those points, accuracy degrades rapidly.
  • Runge's phenomenon: For large offsets |p|, the Lagrange weights grow in magnitude and oscillate in sign, leading to catastrophic cancellation. Best results are obtained for p ∈ [-1, 1] (i.e. interpolating within one grid cell of the reference point).
  • No global spectral accuracy: Unlike the FFT-based circulant approach (lagrange.jl), this method does not leverage the global smoothness of the function. It is designed for speed, not for maximum accuracy on smooth periodic functions.

Use this type when performance is critical and the shift p is small (ideally sub-cell). For large shifts or high accuracy requirements on smooth functions, prefer the spectral circulant approach.

Arguments

  • stencil::Int: Number of grid points used per interpolation. Must be one of {3, 5, 7, 9, 11}. Higher stencil widths give higher polynomial order but increase cost and can amplify instability for large offsets p.

SemiLagrangian.interpolate! — Method
interpolate!(fp, fi, p, interpolant)

Interpolate the periodic array fi at offset p (in grid-spacing units) and store the result in fp.

Boundary points are handled by periodic wrapping: the array is treated as circular, so indices outside 1:n wrap around modulo n.

The interior is processed by the corresponding lagr_Npt_vec! kernel; the stencil/2 - 1 boundary points at each end are filled individually using explicitly wrapped index expressions.

Arguments

  • fp: Output array (length n, modified in-place)
  • fi: Input array (length n, periodic)
  • p: Fractional shift in units of the grid spacing dx. Accuracy is best for p ∈ [-1, 1]; large values lead to weight blow-up and loss of precision (see module disclaimer).
  • interpolant: LocalLagrange object specifying the stencil width

Supported stencil widths

3, 5, 7, 9, 11 (polynomial orders 2, 4, 6, 8, 10 respectively)

Example

n   = 128
fi  = sin.(2π .* (0:n-1) ./ n)
fp  = similar(fi)
lag = LocalLagrange(7)
interpolate!(fp, fi, 0.3, lag)
