Precision

SemiLagrangian provides general-purpose line interpolants as well as specialized methods for repeatedly shifting data on a one-dimensional, uniform periodic grid. This page compares the specialized periodic methods (LagrangeFFT, Spectral, FastLagrange, CubicSpline) with the general-purpose interpolants (Lagrange, Hermite, BSplineLU, BSplineFFT).

The specialized methods use the in-place interface:

interpolate!(output, interpolant, input, shift)

The general-purpose interpolants use the argument order interpolate!(output, input, shift, interpolant).

shift is measured in grid points, not physical-coordinate units. The interpolated values correspond to sampling the input at i + shift; positive shifts therefore move a sampled profile to the left. The input and output must have the grid length used to construct the interpolant. Each method treats the data as periodic, wrapping stencil indices or Fourier phases as needed. Unlike the general Lagrange and Hermite interpolants, these specialized types do not take a bc keyword: periodicity is built into them.

Compare the methods

The following example compares each method with the exact shift of a smooth periodic function. Each interpolant and output buffer is created once and reused. The general-purpose interpolants are used with their default periodic boundary condition (PeriodicBC()):

using SemiLagrangian

n = 128
x = (0:n-1) ./ n
u = sin.(2pi .* x) .+ 0.2 .* cos.(6pi .* x)
shift = 0.3
expected = sin.(2pi .* (x .+ shift / n)) .+
    0.2 .* cos.(6pi .* (x .+ shift / n))
output = similar(u)

methods = (
    "Lagrange FFT" => LagrangeFFT(n, 7),
    "Spectral" => Spectral(n),
    "Fast Lagrange" => FastLagrange(7),
    "Cubic spline" => CubicSpline(n),
)

for (name, interpolant) in methods
    interpolate!(output, interpolant, u, shift)
    println(rpad(name, 20), " max error = ", maximum(abs, output .- expected))
end

general = (
    "Lagrange (order 7)" => Lagrange(7),
    "Hermite (order 5)" => Hermite(5),
    "B-spline LU (order 7)" => BSplineLU(7, n),
    "B-spline FFT (order 7)" => BSplineFFT(7, n),
)

for (name, interpolant) in general
    interpolate!(output, u, shift, interpolant)
    println(rpad(name, 24), " max error = ", maximum(abs, output .- expected))
end

Choosing a method

MethodApproachConsider it when
Spectral(n)Fourier phase shiftThe data is smooth and high accuracy is important. Discontinuities can cause Gibbs oscillations.
LagrangeFFT(n, stencil)Lagrange interpolation with FFT-based periodic convolutionYou want a high-order periodic interpolant and can afford FFT workspaces.
FastLagrange(stencil)Local, fixed-width polynomial stencilShifts are small and avoiding FFT setup is useful.
CubicSpline(n)Cubic interpolation through the FastInterpolations.jl backendA convenient periodic cubic spline is sufficient.
Lagrange(order)Local Lagrange stencil, periodic or extrapolated boundariesYou need non-periodic boundaries or a different element type (BigFloat, Rational...).
Hermite(order)Local Hermite interpolation using derivative estimatesYou want a compact stencil with the Hermite construction (order 5, 9, ... or flbis=true with 3, 7, ...).
BSplineLU(order, n)B-spline interpolation with an LU-factorised spline systemYou need B-splines with periodic or extrapolated boundaries.
BSplineFFT(order, n)Periodic B-spline interpolation solved with FFTsYou need periodic B-splines and want an FFT solve.

The specialized interpolants allocate working arrays when constructed. Reuse each object for successive time steps rather than constructing one per call.

Stencil and order choices

LagrangeFFT takes a grid length and a supported odd stencil width (for example, LagrangeFFT(n, 7)). FastLagrange takes only the odd stencil width; the implementation supports widths 3, 5, 7, 9, and 11. Its weights are intended for small offsets, preferably within about one grid cell. For larger shifts, split the time step or choose an FFT-based method.

Reference

SemiLagrangian.LagrangeFFT — Type
LagrangeFFT(nx, order)

Create a Lagrange interpolation object using FFT-based circulant approach for periodic 1D grids.

This implementation uses a global Lagrange polynomial interpolation via FFT, providing spectral accuracy for smooth periodic functions. The interpolation uses circulant matrix properties to efficiently compute interpolated values via convolution in Fourier space.

Arguments

  • nx::Int: Grid size (number of points)
  • order::Int: Stencil width (number of points). Supports odd orders: 3, 5, 7, 9, 11

LagrangeFFT is a subtype of AbstractInterpolation (through the internal AbstractShiftInterpolation) with the PeriodicBC boundary condition and Float64 numbers. It supports the in-place call interpolate!(u_out, lagr, u, alpha) as well as interpolate!(u_out, u, alpha, lagr), with one constant shift for the whole line.

Fields

  • nx::Int: Grid size
  • order::Int: Polynomial order
  • w::Vector{Float64}: Pre-allocated weight vector
  • bfft::Vector{ComplexF64}: FFT of basis function weights
  • ufft::Vector{ComplexF64}: FFT of input data

Example

lagr = LagrangeFFT(100, 5)  # 100 grid points, order-4 polynomial

SemiLagrangian.CubicSpline — Type
CubicSpline(nx)

Cubic spline interpolation object for periodic 1D uniform grids.

Arguments

  • nx::Int: number of grid points in the periodic domain.

Notes

This wrapper uses FastInterpolations.jl's cubic_interp! under the hood with periodic boundary conditions. It provides a small adapter exposing the SemiLagrangian interpolate! API.

Example

using SemiLagrangian

n = 100
u = sin.(2π .* (0:n-1) ./ n)
u_out = zeros(n)

cs = CubicSpline(n)
interpolate!(u_out, cs, u, 0.5)  # shift by 0.5 grid points
source
SemiLagrangian.Spectral — Type
Spectral(nx)

Create a spectral (Fourier) interpolation object for periodic 1D grids.

Spectral interpolation uses the Fourier representation to interpolate with exponential accuracy for smooth periodic functions. This is the simplest and most accurate method for very smooth data but assumes periodicity.

Arguments

  • nx::Int: Grid size (number of points)

Fields

  • nx::Int: Grid size
  • eigvals::Vector{ComplexF64}: Fourier phase factors (working array)
  • ufft::Vector{ComplexF64}: FFT workspace

Example

spec = Spectral(100)  # spectral interpolation on 100-point grid

SemiLagrangian.interpolate! — Method
interpolate!(u_out, lagr::LagrangeFFT, u, alpha)

Interpolate array u by a displacement alpha (in grid units) using global Lagrange polynomials via FFT convolution.

Arguments

  • u_out::AbstractVector: Output array (will be modified in-place)
  • lagr::LagrangeFFT: FFT-based periodic Lagrange interpolation object
  • u::AbstractVector: Input array (periodic boundary conditions assumed)
  • alpha::Float64: Shift amount in grid-point units. Can be any real number; periodic boundary conditions handle wrapping.

Description

This function computes the interpolated values using:

  1. Lagrange polynomial weights at fractional offset
  2. FFT-based circulant matrix approach for efficiency
  3. Periodic boundary conditions via modular arithmetic

For smooth periodic functions, this provides spectral (exponential) accuracy.

Example

lagr = LagrangeFFT(100, 5)
f = sin.(2π .* (0:99) ./ 100)
f_interp = zeros(100)
interpolate!(f_interp, lagr, f, 0.5)  # shift by 0.5 grid points
source
SemiLagrangian.interpolate! — Method
interpolate!(u_out, interp::CubicSpline, u, alpha)

Interpolate array u onto u_out shifted by alpha grid points using cubic splines. This calls cubic_interp! from FastInterpolations.jl with periodic boundary conditions.

Arguments

  • u_out: preallocated output array (length interp.nx)
  • interp: CubicSpline interpolation object
  • u: input array (length interp.nx)
  • alpha: fractional shift in units of grid spacing (can be non-integer)

SemiLagrangian.interpolate! — Method
interpolate!(u_out, spec::Spectral, u, alpha)

Interpolate array u by a displacement alpha (in grid units) using pure spectral (Fourier-based) interpolation.

Arguments

  • u_out::AbstractVector: Output array (will be modified in-place)
  • spec::Spectral: Spectral interpolation object
  • u::AbstractVector: Input array (periodic boundary conditions assumed)
  • alpha::Float64: Shift amount in grid-point units

Description

This method uses Fourier space phase shifting:

  1. Compute FFT of input
  2. Apply phase shift e^(i * 2π * k * alpha / nx) to each frequency mode
  3. Inverse FFT to obtain interpolated result

Provides exponential accuracy for smooth periodic functions. Caution: only use for smooth data; sharp features or discontinuities will exhibit Gibbs phenomena.

Example

spec = Spectral(100)
f = sin.(2π .* (0:99) ./ 100)
f_interp = zeros(100)
interpolate!(f_interp, spec, f, 0.25)  # shift by 0.25 grid points
